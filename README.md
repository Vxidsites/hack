# 🌌 SINGULARITY: OMEGA CORE

**Interactive Kerr Black Hole Simulator, Relativistic Gravity Sandbox & Cyber Starfighter Combat Engine**

Built entirely with WebGL, custom GLSL Shaders, and the Web Audio API. Zero dependencies, 60+ FPS, real-time astrophysics simulation.

---

## ⚡ What Makes This Mind-Blowing

- **Relativistic Kerr Accretion Disk**: Custom GLSL shader with fractal Brownian motion plasma turbulence, Keplerian differential rotation, and **relativistic Doppler beaming** (approaching side blue-shifted and radiant, receding side red-shifted).
- **Einstein Gravitational Lensing Halo**: Dual-ring accretion disc distortion mimicking real General Relativity (Gargantua / Interstellar style).
- **Tidal Disruption (Roche Limit Spaghettification)**: Throw planets or moons into orbit. If they cross the Roche limit, tidal forces stretch and shred them into spiraling glowing streams of plasma debris before collapsing into the event horizon.
- **Relativistic Polar Jets**: Massive plasma beams blasting from the magnetic poles with periodic shock diamonds and high-velocity relativistic particles.
- **Starfighter Flight Mode ("VOID RAVEN")**: Seamlessly switch into 3rd-person or cockpit view of a stealth cyber-interceptor with 6-DOF Newtonian flight mechanics, hyper-boost afterburners, twin plasma blasters, and gravity-curved singularity torpedoes.
- **Hostile AI Drone Warzone**: Spawn rogue Hunter-Killer drones that dogfight you around the event horizon.
- **Supernova Cataclysm**: Detonate the core to unleash thermonuclear shockwave rings that shatter nearby celestial bodies into millions of sparks.
- **Quantum Hyperspace Slipstream**: Warp into a high-speed hyperspace light tunnel.
- **Pure Web Audio Synthesizer**: 100% procedurally synthesized cosmic sub-bass drones, plasma lasers, explosions, and evolving dark synthwave space music (no mp3s/wavs required!).

| Action | Control |
|---|---|
| **Pitch & Yaw** | `W` / `A` / `S` / `D` or Arrow Keys |
| **Roll / Banking** | `Q` / `E` |

| **Hyperspace Warp** | `H` |
| **Toggle Audio** | `M` |

## 🚀 Running & Sharing

1. **Local Server (Active now)**:
   ```bash
   node server.js
   ```
   Open `http://localhost:8080` in Chrome, Brave, Edge, or Firefox.

2. **Share with Friends on Local Wi-Fi**:
   Find your local IP (`ipconfig`) and have your friends open:
   `http://<YOUR_IP>:8080` on their laptop or phone!
